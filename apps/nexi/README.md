# NEXI

Bichinho virtual para celular: cuide das necessidades, arraste pelo jardim e jogue três minijogos (RUN, CAÇA e POP).

- Arquivo único: `index.html` (sem build).
- Instalável como app (PWA) via `manifest.webmanifest`.
- Progresso salvo no `localStorage` do navegador.

Para rodar localmente: abra `index.html` no navegador.
