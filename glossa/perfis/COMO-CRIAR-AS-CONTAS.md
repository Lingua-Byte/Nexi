# Criar as contas do Glossa (YouTube + Instagram)

Antes de tudo: escolha **um @ livre nas duas redes** e registre-o nas duas no mesmo dia.
Ordem de preferência: `@glossa` → `@glossa.br` → `@canalglossa` → `@glossa.lingua`.
(No YouTube o @ aceita ponto; se `glossa.br` não estiver livre lá, use o mesmo nas duas redes, do jeito que der.)

Dica: crie um **Gmail só para o canal** (ex.: glossa.canal@gmail.com). Ele serve para o YouTube, para o Instagram e, mais tarde, para parcerias.

---

## 1. YouTube (canal focado em Shorts)
1. Entre em youtube.com com o Gmail novo → foto do perfil (canto superior direito) → **Criar um canal**.
2. Nome: **Glossa** · Identificador (@): o que você escolheu.
3. **YouTube Studio → Personalização**:
   - **Imagem do perfil:** `avatar.png`
   - **Banner:** `banner-youtube.png` (já está dentro da área segura do celular)
   - **Descrição:** copie o texto abaixo
   - **Links:** Instagram do Glossa
4. **Configurações → Canal → Informações básicas:** país **Brasil**; palavras-chave (abaixo).
5. **Configurações → Padrões de upload:** idioma do vídeo **Português (Brasil)**, categoria **Educação**.
6. **Configurações → Canal → Configurações avançadas:** "Não, o canal não é para crianças" (o público é adolescente e adulto).
7. Para publicar um Short: no celular, use o botão **+** → **Shorts** e envie o MP4. No computador, use o Studio: **Criar → Enviar vídeos**. Como o vídeo é vertical e tem menos de 3 minutos, ele vira Short automaticamente.
   - Título: o título do `posts.txt` + **#shorts**
   - Descrição: legenda + fonte
   - Use **Programar** para deixar os 7 vídeos do dia agendados (07h, 10h, 12h, 15h, 18h, 20h e 22h).
   - Divulgação de conteúdo alterado ou sintético: marque **não** (narração por IA com imagens gráficas não exige o aviso; imagens realistas geradas por IA exigiriam).

**Descrição do canal (copiar):**
```
Glossa · a língua por dentro.

De onde vêm as palavras? Por que o carioca fala "tchia"? O que é cotexto? Quem decifrou os hieróglifos?
Etimologia, linguística e tudo o que se aprende num curso de Letras, em vídeos de 40 segundos.

Todo dia, 7 vídeos:
07h · De Onde Vem? (etimologia)
10h · Aula de Letras (o curso de Letras em 30 aulas)
12h · Mito ou Verdade
15h · Línguas Extremas
18h · Brasil Falado
20h · Línguas Primas
22h · Gênios da Linguística

Todo vídeo tem fonte. Achou um erro? Comenta: a gente corrige e agradece.
```

**Palavras-chave:**
```
etimologia, linguística, língua portuguesa, curiosidades, letras, português, idiomas, origem das palavras, gramática, enem, sotaque, tupi, latim, mito ou verdade
```

## 2. Instagram
1. Baixe o Instagram → **Criar nova conta** → use o Gmail do canal.
2. Nome de usuário: o mesmo @ do YouTube. **Nome:** `Glossa · etimologia e Letras`. Colocar as palavras no nome ajuda o perfil a aparecer na busca.
3. Foto: `avatar.png`.
4. **Configurações → Tipo de conta e ferramentas → Mudar para conta profissional → Criador de conteúdo**. Categoria: **Educação** (ou "Site de educação").
5. Bio (copiar):
```
A língua por dentro. 🗣️
Etimologia, linguística e o curso de Letras em 40s.
7 vídeos por dia · todo vídeo tem fonte
```
6. Link na bio: o canal do YouTube.
7. Destaques: crie um destaque para cada quadro usando as capas `destaque-1` a `destaque-8`. Para isso, publique cada capa como story e depois adicione ao destaque.
8. Ao publicar: **Novo → Reel** → o MP4 → legenda do `posts.txt` + hashtags → **Opções avançadas → Agendar**.
   - Desative "Também compartilhar no Facebook" se não quiser a página no Facebook.

---

## 3. TikTok (opcional, mas recomendado)
Mesmo processo: conta com o Gmail do canal, mesmo @, `avatar.png` e a mesma bio. Lembre-se de que o programa de recompensas do TikTok só paga vídeos com **mais de 1 minuto**.

---

## Regras para os três perfis
- **Envie o arquivo original** em cada rede. Nunca reposte um vídeo baixado de outra rede com marca d'água.
- **Fixe a fonte nos comentários** de cada vídeo (está no `posts.txt`).
- **Música:** só da biblioteca da própria rede, com volume baixo, sem cobrir a narração.
- **Primeiras 2 semanas:** responda todos os comentários. O algoritmo favorece canais com conversa.
- **Ative a verificação em duas etapas** nas três contas, com o Gmail do canal.
